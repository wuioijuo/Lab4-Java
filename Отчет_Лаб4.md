# Задание 1

## Задача 1.1. Обобщённая коробка

**Требуется:**

Создать обобщённую сущность `Коробка`, которая может хранить один произвольный объект указанного типа.

Необходимо реализовать:

- хранение одного объекта в один момент времени
- возможность поместить объект в коробку и извлечь его
- очистку ссылки на объект после извлечения
- проверку заполненности коробки
- выбрасывание исключения при попытке положить объект в уже заполненную коробку
- работу методов с типом данных, заданным при создании объекта

**Алгоритм решения:**

1. Создать обобщённый класс `Box<T>`.
2. Добавить поле `value` типа `T` для хранения объекта.
3. Реализовать конструктор, создающий пустую коробку.
4. Создать метод `isFull()`, проверяющий заполненность коробки.
5. Реализовать метод `put()`, который помещает объект в коробку и проверяет, что она свободна.
6. Реализовать метод `get()`, который возвращает сохранённый объект и обнуляет ссылку на него.
7. Переопределить метод `toString()` для удобного отображения состояния коробки.
8. Создать коробку типа `Box<Integer>`, поместить в неё число `3`, передать коробку в отдельный метод, извлечь значение и вывести результат.

## Задача 1.2. Без null

**Требуется:**

Создать обобщённую сущность `Хранилище`, которая хранит один объект и является неизменяемой.

Необходимо реализовать:

- передачу объекта в хранилище при создании
- возможность хранения значения `null`
- получение сохранённого значения
- возврат альтернативного значения, если в хранилище находится `null`
- работу с типом данных, указанным при создании объекта

**Алгоритм решения:**

1. Создать обобщённый класс `Storage<T>`.
2. Добавить поле `value` типа `T`.
3. Сделать поле неизменяемым с помощью модификатора `final`.
4. Реализовать конструктор, который принимает значение для хранения.
5. Создать метод `getOrElse()`, который проверяет сохранённое значение.
6. Если значение равно `null`, вернуть переданное альтернативное значение. В противном случае вернуть исходное значение.
7. Переопределить метод `toString()` для отображения содержимого хранилища.
8. Проверить работу хранилища на четырёх примерах:
   - число `null` с альтернативой `0`;
   - число `99` с альтернативой `-1`;
   - строка `null` с альтернативой `default`;
   - строка `hello` с альтернативой `hello world`.

# Задание 2

## Задача 2.3. Начало отсчёта

**Требуется:**

Создать метод, принимающий обобщённую коробку из задачи 1.1 и помещающий в неё трёхмерную точку.

Метод должен поддерживать более одного вида параметризации коробки.

**Алгоритм решения:**

1. Использовать класс `Point` для представления двумерной точки с координатами X и Y.
2. Создать класс `Point3D`, наследующийся от `Point`.
3. Добавить в `Point3D` третью координату Z.
4. Реализовать конструктор, геттеры, сеттеры и метод `toString()`.
5. Создать метод `putOrigin()`, принимающий коробку с нижней границей типа `? super Point3D`.
6. Внутри метода создать объект `Point3D` и поместить его в коробку.
7. Проверить работу метода с коробками типов `Box<Point3D>`, `Box<Point>` и `Box<Object>`.
8. Вывести полученные трёхмерные точки на экран.

# Задание 3

## Задача 3.1. Функция

**Требуется:**

Разработать обобщённый метод, который принимает список значений типа `T` и объект с единственным методом `apply`.

Метод должен применять переданное действие к каждому элементу списка и возвращать новый список значений типа `P`. Типы `T` и `P` могут совпадать или отличаться.

**Алгоритм решения:**

1. Создать функциональный интерфейс `Apply<T, P>` с методом `apply()`.
2. Реализовать обобщённый метод `transform()`, принимающий исходный список и действие для преобразования элементов.
3. Создать новый список для хранения результатов.
4. Перебрать исходный список и применить метод `apply()` к каждому элементу.
5. Добавить полученные значения в новый список.
6. Вернуть сформированный список.
7. Проверить работу метода на трёх примерах:
   - преобразовать строки `qwerty`, `asdfg`, `zx` в числа, соответствующие длине каждой строки;
   - заменить отрицательные числа в списке `1, -3, 7` их положительными значениями;
   - получить максимальные значения из каждого массива целых чисел.

## Задача 3.2. Фильтр

**Требуется:**

Разработать обобщённый метод, который принимает список значений типа `T` и объект с единственным методом `test`.

Метод `test` принимает значение типа `T` и возвращает `boolean`. Необходимо сформировать новый список, в который попадут только элементы, прошедшие проверку.

**Алгоритм решения:**

1. Создать функциональный интерфейс `Test<T>` с методом `test()`.
2. Реализовать обобщённый метод `filter()`, принимающий исходный список и условие проверки.
3. Создать новый список для хранения подходящих элементов.
4. Перебрать исходный список.
5. Для каждого элемента вызвать метод `test()`.
6. Если метод возвращает `true`, добавить элемент в результирующий список.
7. Вернуть новый список.
8. Проверить работу метода на трёх примерах:
   - отфильтровать строки, содержащие менее трёх символов;
   - удалить из списка `1, -3, 7` все положительные числа;
   - оставить только те массивы целых чисел, в которых нет положительных элементов.

## Задача 3.3. Сокращение

**Требуется:**

Разработать обобщённый метод, который принимает список значений типа `T` и способ объединения элементов. Метод должен сводить весь список к одному значению типа `T` и возвращать его.

Необходимо также предусмотреть обработку пустого списка: метод не должен возвращать `null` или выбрасывать ошибку из-за отсутствия элементов.

**Алгоритм решения:**

1. Создать функциональный интерфейс `Combiner<T>` с методом `combine()`, принимающим два значения и возвращающим результат их объединения.
2. Реализовать обобщённый метод `reduce()`.
3. Передавать в метод исходный список, начальное значение и правило объединения элементов.
4. В качестве начального результата использовать переданное значение `identity`.
5. Последовательно перебирать элементы списка и объединять каждый элемент с накопленным результатом.
6. Вернуть итоговое значение.
7. Проверить работу метода на трёх примерах:
   - объединить строки `qwerty`, `asdfg`, `zx` в одну строку;
   - получить сумму чисел `1, -3, 7`;
   - определить общее количество элементов во всех вложенных списках целых чисел.
8. Дополнительно проверить работу метода с пустыми списками строк и чисел. Для пустого списка строк результатом должна быть пустая строка, для пустого списка чисел — `0`.

## Задача 3.4. Коллекционирование

**Требуется:**

Разработать обобщённый метод, который возвращает коллекцию типа `R` со значениями типа `T`.

Метод должен принимать:

- список исходных значений;
- способ создания результирующей коллекции;
- способ передачи значений исходного списка в результирующую коллекцию.

**Алгоритм решения:**

1. Создать функциональный интерфейс `ResultFactory<R>` с методом `create()`, который создаёт результирующую коллекцию.
2. Создать функциональный интерфейс `ResultWriter<R, T>` с методом `add()`, который добавляет исходное значение в результирующую структуру.
3. Реализовать обобщённый метод `collect()`, принимающий исходный список, фабрику результата и способ добавления элементов.
4. Создать результирующую коллекцию с помощью метода `create()`.
5. Перебрать исходный список и передать каждый элемент методу `add()`.
6. Вернуть сформированную коллекцию.
7. Проверить работу метода на трёх примерах:
   - разделить числа `1, -3, 7` на два подсписка: с положительными и отрицательными числами;
   - сгруппировать строки `qwerty`, `asdfg`, `zx`, `qw` по длине;
   - создать набор уникальных строк из списка `qwerty`, `asdfg`, `qwerty`, `qw`, исключив повторения.
